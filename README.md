# Burp Suite Web Security Testing

## 🔐 Project Overview

A team-based web security testing project using **Burp Suite** to capture, analyze, and forward HTTP requests and observe server responses.

## 🎯 Project Objective

- Understand HTTP request and response flow
- Configure Burp Suite Proxy
- Capture web application requests
- Analyze captured HTTP traffic
- Forward requests and observe server responses

## 🛠️ Tools & Technologies

- Burp Suite
- Web Browser
- Gin and Juice Shop
- HTTP/HTTPS

## 👥 Team Project

This project was completed as a team, with different members contributing to different stages of the web security testing process.

## 👤 My Contribution

My contribution focused on the **request forwarding and response observation** stage using Burp Suite.

## 🔄 Project Workflow

1. Opened the web application through the Burp Suite browser
2. Configured **Proxy Intercept**
3. Performed actions on the web application
4. Captured the HTTP request in Burp Suite
5. Forwarded the request
6. Observed the server response
